# Decurian Ltd — site (staging)

Static preview of the medical imaging equipment broker site (4 concept directions, A/B/C/D switcher).

Rebuild from ../build: `node build/inject-deploy.mjs`
Deploy: from this folder run `npx vercel` (preview) or `npx vercel --prod`.

NOTE: content is placeholder except the name (Decurian Ltd) and phone; site is noindex until a concept is chosen.
